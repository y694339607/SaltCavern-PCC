# predictions/ · 预测点云

> Bilingual document: English first, Chinese below. · 中英双语：上为英文，下为中文。

## English

Normalised prediction clouds for the released benchmark. **Binary files are ignored by git**
(`.gitignore`); they are distributed as the asset `predictions_v1.0.tar.gz` of the GitHub Release `data-v1.0`.

```
predictions/
├── MANIFEST.csv          index -> cavity / level / source file names
├── SHA256SUMS.txt        one line per .npy (sha256, relative path)
├── test/
│   ├── gt/               150 complete clouds, 16384 x 3 float32
│   └── pred_{cylnn,spline,idw,adapointr_masked,adapointr_full,pcn,pointr}/   150 each
├── val/
│   ├── gt/               150 complete clouds
│   └── pred_{adapointr_masked,adapointr_full,pointr,pcn}/                    150 each
└── repeats/
    ├── order1/pred_{adapointr_masked,adapointr_full}/   first data-order repeat, 150 each
    └── order2/pred_{adapointr_masked,adapointr_full}/   second data-order repeat, 150 each
```

### What each group supports

| Group | Manuscript |
|---|---|
| `test/pred_*` (7 arms) + `test/gt` | Table 4 (test columns), Table 5, Table 6, Figure 6 |
| `val/pred_{adapointr_masked,adapointr_full,pointr,pcn}` + `val/gt` | Table 4 (val columns for these arms), Figures 8–9 |
| `repeats/order1`, `repeats/order2` | Table 7, Table 8 |

Arm names follow the naming convention in the root README: `cylnn` cylindrical nearest neighbour,
`spline` periodic spline, `idw` inverse-distance weighting, `adapointr_masked` AdaPoinTr with
blind-zone masked supervision, `adapointr_full` AdaPoinTr with full-region supervision, `pcn` PCN,
`pointr` PoinTr.

### Fields

All arrays are `(16384, 3)` float32 in the recorded coordinate frame (radial coordinates in metres,
vertical coordinates retaining foot values; the affine map `z_m = 0.3048 z` is documented in
`docs/DATASET.md`). File index `i` maps to a cavity and coverage tier through `MANIFEST.csv`, which
is identical to the row order of `data/splits/samples.csv` for the same split.

### Using these files

The evaluation scripts take a prediction root and look for `pred_<arm>/<i:03d>.npy`:

```bash
export SCC_ROOT=/path/to/benchmark_root
python code/evaluation/volume_pipeline.py \
    --split test \
    --pred_root predictions/test \
    --gt_dir predictions/test/gt \
    --field_dir $SCC_ROOT/dataset/pc_v2/test/gt_field \
    --methods adapointr_masked,adapointr_full,pcn,pointr,cylnn,spline,idw \
    --outdir /tmp/vol
```

### Deliberately not included

| Not included | Reason |
|---|---|
| ID-1024 / ID-8192 clouds | Fully determined by the observations and the documented Philox draw (`SeedSequence(20260921, [cavity, level, 2])`); shipping them would duplicate the observation archive. |
| An internal PoinTr variant (`GPtrV`) | Its mean V_ref error on the validation split is 16.4 %, against 9.7 % for the released PoinTr arm, so it is not the configuration reported in Table 4. |
| Blind-window ablations (`GBMw30`, `GBMw100`) | No row of the manuscript reports them. |
| Validation predictions of the rule-based baselines | Not archived. Cyl-NN, periodic spline and IDW are deterministic and are regenerated by `code/baselines/baseline_recon.py` in a few seconds. |
| Placebo and initialization-repeat clouds | Not archived as clouds; their per-sample metrics are released in `results/placebo_init_per_sample.csv` and `results/init_repeats_per_sample.csv`. |
| Per-directory `*_sha256.txt` and `*_mapping.csv` | Replaced by the single `SHA256SUMS.txt` and `MANIFEST.csv` at this level. |

## 中文

发布用预测点云的规范树。**二进制文件被 git 忽略**（`.gitignore`），随 GitHub Release `data-v1.0` 的资产
`predictions_v1.0.tar.gz` 发布。

目录结构与上节相同：`test/` 含 7 个臂的预测与 150 件完整真值；`val/` 含 4 个臂与真值；
`repeats/order1`、`repeats/order2` 为两次数据顺序重复的掩码与全区域两臂。
`MANIFEST.csv` 给出「序号 → 腔号 / 档位 / 源文件名」的映射，`SHA256SUMS.txt` 每行一个文件的
SHA-256。

### 各组支撑论文的哪些内容

| 目录 | 对应论文 |
|---|---|
| `test/pred_*`（7 臂）+ `test/gt` | 表 4 测试列、表 5、表 6、图 6 |
| `val/pred_{adapointr_masked,adapointr_full,pointr,pcn}` + `val/gt` | 表 4 中这几个臂的验证列、图 8–9 |
| `repeats/order1`、`repeats/order2` | 表 7、表 8 |

臂名与根目录 README 的命名约定一致：`cylnn` 柱面最近邻、`spline` 周期样条、`idw` 反距离加权、
`adapointr_masked` AdaPoinTr 盲区掩码监督、`adapointr_full` AdaPoinTr 全区域监督、`pcn` PCN、
`pointr` PoinTr。

### 字段

全部为 `(16384, 3)` float32，处于记录坐标（径向为米，垂向保留英尺数值；仿射映射
`z_m = 0.3048 z` 见 `docs/DATASET.md`）。文件序号 `i` 通过 `MANIFEST.csv` 对应到腔号与观测档位，
其行序与 `data/splits/samples.csv` 中同一划分的行序一致。

### 使用方式

评价脚本接收一个预测根目录，并按 `pred_<臂>/<i:03d>.npy` 查找文件，命令示例见上节。

### 有意未收录的内容

| 未收录 | 原因 |
|---|---|
| ID-1024 / ID-8192 点云 | 完全由观测与已记录的 Philox 抽样
（`SeedSequence(20260921, [腔号, 档位, 2])`）确定，收录会与观测归档重复。 |
| 内部 PoinTr 变体（`GPtrV`） | 其验证集 V_ref 平均误差为 16.4%，而发布的 PoinTr 臂为 9.7%，
因此它不是表 4 所报告的配置。 |
| 盲窗宽度消融（`GBMw30`、`GBMw100`） | 论文没有任何一行报告这两个结果。 |
| 规则化基线的验证集预测 | 未归档。柱面最近邻、周期样条与反距离加权均为确定性算法，
`code/baselines/baseline_recon.py` 数秒即可重生成。 |
| 安慰剂与初始化重复的点云 | 未以点云形式归档；其逐样本指标已发布在
`results/placebo_init_per_sample.csv` 与 `results/init_repeats_per_sample.csv`。 |
| 各目录内的 `*_sha256.txt` 与 `*_mapping.csv` | 已由本层的 `SHA256SUMS.txt` 与 `MANIFEST.csv` 取代。 |
